## Typical artifacts

## Co-Development Toolkit skill set
The `sco-*` skills turn the [NASA Earth Science Solution Co-Development Toolkit](https://science.data.nasa.gov/earth-science-solution-co-development-toolkit/) fillable templates into guided agent runs that emit the same tables (plus CSV for paste-back) and share one `solution-profile.yaml`. Start with `sco-toolkit-orchestrator`; full chain in [`workflows/partner-need-to-co-developed-solution.md`](../workflows/partner-need-to-co-developed-solution.md).
